# ЭкоЛоток — интерактивная презентация для конкурса «100 идей для Беларуси»

Готовая премиальная презентация (тёмная тема, glass-morphism) на **React + Framer Motion + Vite**,
объединяющая оба проекта в единый сценарий питча перед жюри:

| # | Раздел | Что внутри |
|---|--------|-----------|
| 1 | Титул | Брендинг, ключевые цифры пилота, «парящий» лоток с RFID-волнами |
| 2 | Проблема | Статистика по одноразовой таре + сравнительные бары «до/после» |
| 3 | Механизм | **Анимированный SVG-цикл работы лотка**: QR, вес-датчик, RFID-стойка, возврат залога |
| 4 | Демо | **Живой интерактивный лоток**: кладёте товары кликом → сдаёте у стойки → летит монета «+0,50 Br», печатается чек возврата |
| 5 | Сети магазинов | **Детальная статистика по сетям** (Евроопт, Светофор, HIT, Нептун, Full Price): точки, лотки, возвраты/сутки, удержание, CO₂, мини-карта городов |
| 6 | Экономика | Растущий график оборота по месяцам + юнит-экономика одного лотка |
| 7 | Экология | Анимированные счётчики и donut-диаграмма цикла жизни тары |
| 8 | Roadmap | Дорожная карта от пилота до национального стандарта |
| 9 | Финал | Призыв к жюри: грант, сеть-партнёр, экспертиза |

## Управление
- Кнопки «Назад / Далее», точки-навигация внизу, прогресс-бар сверху
- Клавиши: `←` `→` / `PgUp` `PgDn` / `Пробел` — листать, `Home`/`End`, `F` — полноэкранный режим (для экрана жюри)
- Свайпы на сенсорном экране/планшете

## Запуск
```bash
npm install        # зависимости уже установлены в node_modules
npm run dev        # разработка → http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # просмотр сборки → http://localhost:4173
```

## Как показать офлайн на выступлении
Соберите проект (`npm run build`) и просто откройте файл `dist/index.html`
в браузере (double-click) — сборка использует относительные пути и работает
без интернета. Шрифты подгружаются с Google Fonts; без сети будет использован
системный шрифт — вёрстка не поедет.

## Данные
Все цифры пилота (сети, точки, лотки, возвраты, CO₂) хранятся в одном файле
`src/data.js` — замените демонстрационные значения на реальные из ваших
выгрузок, вся презентация и графики пересчитаются автоматически.
